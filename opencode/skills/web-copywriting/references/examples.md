# Copy examples

Use these patterns to keep public copy natural, specific, and honest.

## Remove internal-sounding language

Before: “Evidencia visual disponible en el expediente.”
After: “Ver análisis y fuentes.”

Before: “Kit observado: medidas atribuidas pendientes.”
After: “Qué incluye: confirma accesorios y medidas de esta versión.”

Before: “Punto de vigilancia: seguridad.”
After: “Ten en cuenta: usa protección ocular y evita dirigir el chorro a personas.”

## Hero and comparison

Start from the job, then narrow choice:
“¿Buscas limpiar el coche sin ocupar media terraza? Compara modelos compactos por presión, caudal, accesorios y límites de uso antes de elegir.”

Useful contrast names its audience:
“El modelo A encaja mejor si valoras poco espacio y tareas ligeras; el modelo B ofrece más margen para superficies amplias, con mayor peso.”

## Honest CTA

Label links by destination:
“Ver ficha técnica del fabricante” → manufacturer page.
“Consultar disponibilidad” → real retailer offer.
Never use “Comprar” for a guide, source, or comparison page.

## Supported claim

Source fact: hose length is 8 m versus 3 m.
Copy: “Los 8 m ofrecen mayor alcance que los 3 m, si el resto de la instalación permite aprovecharlos.”
Do not turn that fact into “limpia más rápido” or “limpia mejor” without evidence.

## Transferable service example

“Si tu equipo pierde tiempo en tareas repetidas, ordenamos el flujo actual y dejamos próximos pasos claros.”
“Solicitar diagnóstico inicial” is honest only when it opens the stated service.

## SEO rationale

Google Search Central asks whether content is useful to its intended audience and says there is no preferred word count: [Creating helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content).
It also recommends descriptive page titles for search title links: [Title links](https://developers.google.com/search/docs/appearance/title-link).
