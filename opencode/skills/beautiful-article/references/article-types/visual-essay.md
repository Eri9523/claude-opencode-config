# Article Type · visual-essay

Showcasing, dissemination, visual-and-text-led pieces, brand storytelling, year-end reviews, cultural commentary. **Visuals are the star**, text is short and sharp, pacing is strong.

- **Recommended retention**: 20-60% (keep only the core point and the most powerful material; heavily cut narrative / derivation / data detail, and reorganize what remains through visuals).
- **Typical structure**: `Hero` (strong character / full-bleed visual / large headline) → a string of short `Section`s, each = sparse text + a large visual + one memorable line → **strong pacing contrast** between sections (sparse/dense, light/dark) → `Conclusion` (a whitespace-led close / a one-line summary). **Sections are short** — 30 seconds to 1 minute of reading time each.
- **Component choice**: prose uses **short sentences and line breaks**; `Quote` provides a punchy pause (not citing famous quotes, but pulling the article's own "hard-hitting lines" out as section markers); `Image` / `Raw` are the stars; **use dense data components sparingly** (`Table` / `RiskList` break the visual rhythm).
- **Raw boundary**: **visual blocks make up the largest share** — large-scale layouts, pacing graphics, concept visualizations, motion, light interactivity (HTML/CSS/React, SVG/canvas as needed); it's fine to use **full-bleed backgrounds**, **scroll-triggered motion**, **staggered multi-column layouts**, and the like. But it **must still take the form of an article** — not a landing page, not a product dashboard.
- **Imagery tendency**: `ai-generated` / `user-assets` **large imagery**; composition / whitespace / layout are themselves a form of expression; avoid stock photos and cliché "business handshake"-type imagery.
- **Theme tendency**: `bodoni` (black-and-white glossy magazine), `press` (warm editorial), `sottsass` (lively and colorful), `bayer` (modernist / poster-like), `andy` (soft narrative). Themes with strong character work best in this type.
- **Self-check**:
  - Is it still an **article**, rather than a poster / landing page / dashboard? (After removing all visuals, does the remaining text still string together into a point? Yes = article; no = landing page.)
  - Do the visuals serve the **core point**, rather than being pure decoration / showing off?
  - Does the pacing have room to breathe (sparse/dense contrast, light/dark contrast, size contrast)?
  - After trimming, does it still read like "an edited article" rather than "a shrunken summary"?
  - Does it still convey the core point on mobile (many large-scale layouts collapse on mobile)?

> **When not to use visual-essay**:
>
> - Helping the reader make a decision → `briefing`.
> - Giving the reader complete understanding → `longform` / `explainer`.
> - Having the reader **learn by operating it** → `interactive-explainer` (also visual-led, but the reader must get hands-on).
> - Conveying a complete argument / dataset → `essay` / `full-report`.
