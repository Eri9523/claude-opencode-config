# Laws of UX

Use [Laws of UX](https://lawsofux.com/es/) as a focused reference for psychology principles applied to interface design.

Official agent index: https://lawsofux.com/es/llms.txt

## Workflow

1. Understand the user goal, audience, task, and interface context.
2. Select only laws relevant to the observed problem.
3. Connect evidence, applicable law, and proposed change explicitly.
4. Prefer measurable recommendations over generic psychology claims.
5. Validate the result with accessibility and usability checks.
6. Treat laws as heuristics, not absolute rules or substitutes for user research.

## Common Matches

- Too many choices: Hick's Law and choice overload.
- Small or distant controls: Fitts's Law.
- Unfamiliar interactions: Jakob's Law and mental models.
- Dense information: cognitive load, working memory, and chunking.
- Weak grouping: proximity, similarity, common region, and uniform connectedness.
- Slow feedback: Doherty Threshold.
- Important action lacks emphasis: Von Restorff Effect.
- Long multi-step flow: Goal-Gradient Effect and Zeigarnik Effect.
- Critical beginning or ending moments: Serial Position Effect and Peak-End Rule.
- Avoidable complexity: Occam's Razor; preserve unavoidable complexity under Tesler's Law.
