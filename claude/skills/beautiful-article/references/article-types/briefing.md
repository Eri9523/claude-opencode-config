# Article Type · briefing

For **quick judgment** by busy readers (decision-makers / colleagues / investors). Readers **will not read the whole thing**, so every paragraph must help them decide.

- **Recommended retention**: 40-60% (keep only the key conclusions, key evidence, key trade-offs, and next steps; cut all setup / derivation / background / history).
- **Typical structure**: `Hero` (headline = the conclusion in one sentence) → `Summary` (**conclusion first + 3-5 key facts** — the most important block) → `Section`: key evidence → trade-offs / risks → next steps / action items. **Keep it short and tight; total reading time should be 3-5 minutes.** A `Conclusion` isn't necessary (the `Summary` already states the conclusion).
- **Component choice**: still **prose-first**, with short, direct sentences (ideally no more than 3 sentences per paragraph). `Summary` is the core — it's the soul of a briefing. Everything else is used as needed:
  - `Table`: when N items genuinely need side-by-side comparison.
  - `Decision` / `Tradeoff`: when there's a genuine "X vs Y" trade-off to show.
  - `ActionList`: when there are genuine next steps to list (who does it / when).
  - **Don't stack components just because it's a briefing** — a briefing's value is its concision; too many components make it look bloated.
- **Raw boundary**: few but impactful — one **key comparison chart** / trend / options matrix / decision tree; don't stack visuals. A briefing typically has 0-2 Raw blocks.
- **Imagery tendency**: `none` or a **single key image** (data chart / key screenshot); leans toward `tufte`'s evidentiary feel or `press`'s clean editorial feel.
- **Theme tendency**: `tufte` (data-driven briefings), `vignelli` (neutral/spec-like), `press` (editorial pacing).
- **Self-check**:
  - Can the conclusion be grasped within 30 seconds (reading only Hero + Summary)?
  - Does every paragraph **help the decision** (would removing it affect the decision)?
  - Is there any redundant elaboration / rationale / historical background / "here's why" paragraph?
  - Are the action items actionable (who does it / when / how is it verified)?
  - Is the total reading time really 3-5 minutes? If it exceeds that, it isn't a briefing anymore.

> **When not to use briefing**:
>
> - The reader needs to **fully understand** something rather than make a quick judgment → `longform` / `full-report` / `explainer`.
> - Reviewing a specific artifact → `review`.
> - The reader needs to **truly learn** a concept → `explainer` / `interactive-explainer`.
